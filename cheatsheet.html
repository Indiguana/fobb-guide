Foundations (Ch. 1–4)

Dysfunctional brain (Ch. 5–7)

Ceiling / floorToo easy / too hard → can't detect differences
Single dissociationLesion impairs X, spares Y. Weaknesses: task sensitivity, general impairment, serial vs parallel ambiguity
Double dissociationLesion A: X✗ Y✓; lesion B: Y✗ X✓. Fixes all three; supports parallel
Blood~20% of blood flow · 10 s blocked → unconscious. ACA frontal + parietal · MCA temporal + parietal · PCA occipital + temporal
VesselsAtherosclerosis (plaques) · AVM (artery→vein tangle) · aneurysm (bulge; clip or coil)
StrokeIschemic = blocked (clot, plaque) · hemorrhagic = burst. F.A.S.T.
AphasiaBroca's: production ✗, comprehension ✓, singing intact · Wernicke's: comprehension ✗, production ✓ (fluent)
TBIDirect force / coup–contrecoup → contusions (orbitofrontal → social regulation) · diffuse axonal injury (rotation shears axons → coma)
CTERepeated trauma ± LOC; frontal tau. 1 headache/attention → 2 depression/explosivity/STM → 3 executive → 4 dementia/aggression
Cerebellum>80% of neurons; hereditary; ataxia (over/undershoot); generates sensory predictions (can't tickle yourself)
Parkinson'sSporadic; 40–80 yrs; SN dopamine loss. Bradykinesia, rigidity, rest tremor (~3 Hz), loss of righting reflex. ↓DA → ↓striatum → ↑GPi → ↑thalamic inhibition → ↓cortex
TreatmentsL-dopa (adds DA; → dyskinesia via influx + receptor sensitization) · DBS shuts off GPi → releases thalamus
Huntington'sGenetic; ~40 yrs. No-go striatum lost → ↑GPe → ↓STN → ↓GPi → ↑movement: chorea + dementia
HemiballismusDemyelination of BG circuitry → one-sided flinging movements
Alzheimer's60–80 (slides). Amyloid plaques between neurons; tau tangles inside. Hippocampus. Working memory ✓, old LTM ✓, forming new memories ✗
